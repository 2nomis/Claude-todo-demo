# Die Klänge

Nur diese werden benutzt: Sie stammen alle aus den veröffentlichten Reels des Creators, und die mit ✓ liefen in Videos
von ihm, die er mit den Effekten freigegeben hat (das Promo-Video und der grüne Stern). In `klaenge.js` wird jeder mit
seinem Namen verlangt (ohne die Endung).

| Name | Was es ist | Wofür |
|---|---|---|
| `wusch` ✓ | ein kurzes, weiches Wusch, wie etwas, das schnell nah vorbeifliegt | die Kamera bewegt sich, etwas kommt herein oder fliegt vorbei |
| `stoss` ✓ | ein starkes Wusch, das näher kommt und abrupt endet | auf etwas zuschießen, in sich zusammenfallen, quetschen |
| `explosion` ✓ | eine große Explosion und ihr Grollen | etwas platzt oder stirbt mit einem Blitz; rückwärts ein tiefer Anstieg |
| `fels` ✓ | ein trockener Steinschlag mit kleinen Stücken | etwas aus Stein zerbricht oder schlägt ein |
| `dumpf` ✓ | ein fester, dumpfer Schlag | etwas schlägt ein oder landet hart |
| `dumpf-tief` ✓ | ein tieferer dumpfer Schlag | der größte Aufprall |
| `klick` ✓ | ein kurzer, sauberer Klick (den der Creator ausgesucht hat) | etwas erscheint, wird markiert oder hält an |
| `tick` ✓ | ein klappernder Tick | eine Zahl, die hochzählt; etwas, das klappert |
| `anstieg` ✓ | ein kurzes Wusch nach oben | etwas steigt oder entfernt sich |
| `schlag` ✓ | das Klicken des Strohhalms | der Puls des Hauptdings (immer derselbe) |
| `quetsch` ✓ | etwas Weiches, das gequetscht wird | quetschen, zerdrücken |
| `metall` ✓ | ein starker Metallschlag | etwas aus Metall schlägt ein oder rastet ein |
| `holz` ✓ | ein Klopfen auf Holz | etwas fällt auf Holz |
| `tipp` ✓ | ein Fingertippen auf Glas | einen Bildschirm oder ein Glas berühren |
| `gleiten` ✓ | ein Metallteil, das gleitet | etwas gleitet |
| `glas` | ein Glas, das abgestellt wird, klar und kurz | etwas aus Glas landet oder klirrt |
| `wand` | ein schwerer Block, der an seinen Platz fällt | etwas sehr Schweres hält an |
| `knirschen` | etwas aus Metall, das unter Druck zerdrückt wird | quetschen, bis es bricht |
| `einrasten` | ein kleines metallisches Klacken | etwas Kleines aus Metall rastet ein |
| `rahmen` | ein schwerer Holzrahmen auf einem Tisch | etwas Schweres aus Holz wird abgestellt |
| `barren` | Metallbarren, die aufeinander fallen | etwas Dichtes aus Metall fällt |
| `holzbruch` | ein Holztisch, der zerbricht | Holz zerbricht |
| `papier` | eine Zeitung, die flach auf einen Tisch fällt | Papier, Briefe, Fotos |
| `ball` | ein Ball, der zweimal aufspringt | etwas springt auf |
| `glocke` | eine Fahrradklingel, zweimal | ein fröhlicher Hinweis |
| `piep` | ein kurzer elektronischer Piepton | ein Gerät, das misst oder warnt |
| `hohl` | ein hohles metallisches Klopfen (ein Helm) | etwas Hohles aus Metall |
| `kanone` | ein tiefer Kanonenschuss mit Echo | ein riesiger Schlag in der Ferne |
| `erde` | ein Sprung, der auf Erde landet | etwas fällt auf weichen Boden |
| `hinweiston` | eine Handy-Benachrichtigung | eine Nachricht kommt an |

Woher sie kommen: aus dem Kit des U-Bahn-Reels (`wusch`, `stoss`, `klick`, `tick`, `anstieg`, `metall`, `holz`, `tipp`,
`gleiten`, `glas`, `wand`, `knirschen`, `einrasten`), aus dem des Strohhalm-Reels (`schlag`, `quetsch`) und aus dem des
Reels über Schloss Itter (der Rest).
